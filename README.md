# 栈闩工房

机关推箱子纯前端工房。不同种类的箱子触发对应踏板，踏板改变门与地板，记录步数并保存已完成关卡的最佳成绩。

## 搬运工法账

每关成绩不再只按总步数排名，而是按“搬运工法”分别记账：

- **推次**只统计真正改变货位的推箱；不推箱的空走、绕路只算脚步，不另成一种工法。
- 两次推若满足以下全部条件，即视为可交换、属同一工法：换序后两推都合法（允许先空走到箱后）、每推各自引起的门/地板与目标格变化不变、终局箱位与人能空走到的区域相同。
- 同材质箱走不同入口时，按箱与初始货位的对应关系留痕，保住“哪个货位被腾空”，不会因终局落点相同而混为一类。
- 识别时对推迹逐对做相邻交换规范化（可能连续交换数次），开门又关回的中间一拍逐推留痕、不可省略，再据规范推迹生成工法指纹。
- 同一工法只保留最少的**实走步数**；在工法账页点两次相邻的推，可查看它们为什么能或不能交换。
- 老版本只存了步数、没有推迹的成绩会原样迁入，账页中只列数值，不猜测其工法归属。

## 本地运行

```bash
npm install
npm run dev
```

类型检查与生产构建：

```bash
npm run typecheck
npm run build
```

## Docker

```bash
docker compose up --build
```
